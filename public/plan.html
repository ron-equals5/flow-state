01

The approach

Arketa is the system of record. Everything the custom layer can't do through Arketa's API falls back to Arketa's own widgets and branded app, so nothing blocks opening day.

Arketa runs the business

  • Clients, memberships, packs and payments
  • Waivers and waitlists
  • Front-desk POS and hardware
  • Payroll reporting and staff tools
  • Email and SMS marketing
  • Branded client app and video on demand

The Flow State layer

  • Branded website on Cloudflare
  • Schedule with instructor, class type, class name and heat filters
  • Class description library and instructor profiles
  • The Flow booking: pick a block, then a start time
  • Reset Room booking with invite-a-guest
  • Lead capture that feeds Arketa's CRM
Rule of thumb: if Arketa does it well, use Arketa. If it's how clients see and book Flow State, or something Arketa can't do, build it on Cloudflare.

Infrared-heated studio

Reset Room

Wellness & recovery

Self-serve equipment, rented by the time slot.

Custom

The Flow

A video-guided drop-in circuit. Each start time is set up as a small class in Arketa. Our picker shows two steps: choose the block, then choose a start time, with live spots for each.

CustomBiggest risk

Reset Room

One person books the slot and invites one other: an existing member, or a first-time guest with a guest pass and waiver. The API can't book rooms, so we'll confirm in the Arketa demo whether a two-spot class works. If not, it gets its own booking engine on Cloudflare.

Custom

Restricted Flow blocks

Flow blocks limited to certain clients. Who they're for and how they're enforced still need defining. Arketa can likely limit which purchases are valid for a class.

Arketa native

Instructor-led classes

Standard classes tagged by type, floor and heat, shown in our filtered schedule.

Arketa native

Pop-ups & Events

Their own pricing, and member credits don't apply. Event pages on our site, with checkout through Arketa.

Arketa native

Workshop Series

Several classes sold as one purchase. Series pages on our site, with checkout through Arketa.

08

Open questions

For the studio

  1. Opening date. What's the exact date, and when must booking go live?
  2. The Flow. How long are the blocks, how often do start times run, how many per start, and how long is the circuit?
  3. Restricted Flow blocks. Who are they restricted to, and why?
  4. Reset Room. Slot length and price? Do credits apply? How do guest passes work?
  5. Pricing. The full list for memberships, packs, single classes, events and series.
  6. On-demand video. Needed at launch or later? Where will the content come from?
  7. Hardware. Which card reader and receipt printer? Is door access in scope?
  8. Staff chat. In Arketa, or a separate tool like Slack or WhatsApp?
  9. Content. Who supplies class descriptions, instructor bios and photos, and when?

For the Arketa demo

  1. Suite price. Exact monthly price, and is there an annual discount?
  2. Branded app. Included in Suite, or a paid add-on?
  3. Processing. Any Arketa markup on Stripe rates for studio plans?
  4. SMS. What do text messages and campaigns cost?
  5. Setup. Is there an onboarding fee?
  6. Hardware. Which readers, printers and cash drawers are supported?
  7. Reset Room. Can a room rental work as a two-spot class with a guest invite?

Risks

Timeline

Opening this month

Phase 1 relies on Arketa as it comes, and custom work follows opening.

Platform

Arketa API is "as-is"

No sandbox or webhooks. We'll use a test location, polling with caching, monitoring, and fallback to Arketa widgets.

Booking

Reset Room can't be booked via API

Confirm the setup in the demo. The fallback is our own booking engine on Cloudflare.

Data

Data in two places

Arketa is always the source of truth. Our layer only caches and links to it.
